# Drawing Prototype

A simple drawing canvas prototype built with **React** to practice canvas drawing and backend integration.

## Features

* ✏️ Freehand drawing
* ↩️ Undo support
* ↪️ Redo support
* 🗑️ Clear canvas
* 💾 Save drawings to the backend
* 📂 Load saved drawings

## Tech Stack

* React
* HTML5 Canvas API
* Express.js
* Node.js
* Fetch API

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Parth-Vaidya/Drawing-prototype-Canva-
cd ./client
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the frontend

```bash
npm run dev
```

### 4. Start the backend

```bash
npm start
```
